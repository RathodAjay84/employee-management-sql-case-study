Employee Management SQL Case Study (MSSQL)
📌 Overview
This project is a comprehensive SQL case study focused on analyzing employee, department, job, and location data. It simulates real-world business scenarios such as employee performance evaluation, department-wise analysis, and salary insights using structured SQL queries.

🎯 Objectives

Analyze employee data across departments and locations
Evaluate salary distribution and commission patterns
Perform department-wise and job-wise analysis
Apply SQL concepts to solve real-world HR and business problems


🛠️ Tools & Technologies

Microsoft SQL Server (MSSQL)
SQL (Structured Query Language)
VS Code


📊 Dataset Description
🔹 Employee Table

Employee ID, Name, Job ID
Hire Date, Salary, Commission
Department ID

🔹 Department Table

Department ID, Department Name
Linked with Location

🔹 Job Table

Job ID, Designation

🔹 Location Table

Location ID, City


🔍 Key Analysis Performed

Employee filtering using WHERE conditions
Salary analysis using aggregation functions
Department-wise and job-wise insights
Monthly and yearly hiring trends
Ranking employees based on salary
Identifying employees above department average salary


⚙️ SQL Concepts Used

Joins (INNER JOIN)
Subqueries (Nested Queries)
Aggregations (SUM, AVG, COUNT, MIN, MAX)
GROUP BY & HAVING
ORDER BY
CASE Statements (Conditional Logic)
Window Functions (DENSE_RANK)
Data Filtering (LIKE, BETWEEN, IN, NOT IN)
